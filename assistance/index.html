Questions fréquentes

L'assistant vocal ne répond pas

Vérifiez que l'assistant vocal est activé dans l'app (Réglages) et que Stable Manager a accès au micro (Réglages de l'iPhone → Stable Manager → Micro). L'assistant a besoin d'une connexion internet.

Je ne reçois pas les rappels de mes rendez-vous

Autorisez les notifications : Réglages de l'iPhone → Stable Manager → Notifications. Les rappels arrivent la veille de l'événement.

Je n'ai pas reçu l'email de confirmation de mon compte

Regardez dans vos courriers indésirables. Si vous ne le trouvez pas, écrivez-nous.

J'ai oublié mon mot de passe

Écrivez-nous depuis l'adresse email de votre compte, nous vous aiderons à retrouver l'accès.

Supprimer mon compte

Dans l'app : Réglages → Supprimer mon compte. Votre compte et toutes les informations de votre écurie sont effacés définitivement.
